# «Стежка» — встановлення на телефон

Усі файли лежать поруч, без тек. Заливати треба **всі дев'ять**:

```
index.html
manifest.webmanifest
sw.js
icon-192.png
icon-512.png
icon-maskable-512.png
apple-touch-icon.png
favicon-32.png
README.md
```

## 1. Викласти на GitHub Pages

1. Створи новий репозиторій, назви `stezhka`.
2. На сторінці репозиторію: **Add file → Upload files**.
   Виділи всі файли одразу й перетягни у вікно → **Commit changes**.
3. **Settings → Pages** → Source: *Deploy from a branch*, Branch: **main**,
   папка **/ (root)** → **Save**.
4. За хвилину-дві застосунок буде тут:
   `https://nataliatronza.github.io/stezhka/`

## 2. Поставити на телефон

1. Відкрий цю адресу **в Chrome** на телефоні.
2. Меню «⋮» → **Встановити застосунок** (або *Додати на головний екран*).
   Те саме можна зробити кнопкою в розділі **Я → Дані й телефон**.
3. Готово — іконка з альпакою на екрані, запуск на весь екран.

Якщо пункту «Встановити застосунок» немає — перезавантаж сторінку ще раз:
service worker реєструється не миттєво.

## 3. Офлайн і дані

- Після першого запуску з інтернетом застосунок працює **без мережі**.
  Шрифти вбудовані в `index.html`, тож нічого не підвантажується ззовні.
- Усі записи живуть **лише на цьому телефоні** (у памʼяті браузера).
  Раз на кілька тижнів роби **Я → Зберегти копію** — це файл `.json`,
  з якого все відновлюється кнопкою **Відновити з файлу**.
- Дані «Стежки» зберігаються під власним ключем і не перетинаються
  з іншими твоїми застосунками на `nataliatronza.github.io`.

## 4. Нагадування

Таймер прогулянки й нагадування про перерву працюють, поки застосунок
відкритий або щойно згорнутий. Дозволь сповіщення, коли телефон спитає.
Якщо екран вимкнений довго, Android може притримати нагадування — це
обмеження браузерних застосунків, не помилка.

## Оновлення

Нову версію `index.html` просто заливаєш поверх старої — телефон підхопить
її сам при наступному запуску з інтернетом. Номер версії в `sw.js`
(зараз `stezhka-v2`) треба міняти, лише якщо змінюються **іконки**.

Якщо ти вже встановлювала першу версію (з ведмедиком) — заміни в репозиторії
**всі файли**: іконки нові, і `sw.js` уже з новою версією. Записи на телефоні
збережуться, а норма кроків сама виправиться з 8 000 на 7 000.
Іконка на головному екрані Android іноді оновлюється не одразу. Якщо
лишився ведмедик і хочеш перевстановити — спершу збережи копію
(**Я → Зберегти копію**), а після встановлення відновиш її з файлу.
